# ctPWAS: Cell-Type-Level Proteome-Wide Association Studies

`ctPWAS` is an R package for **cell-type-level proteome-wide association studies (PWAS)** using bulk proteomic data and genome-wide association study (GWAS) summary statistics.

Conventional PWAS rely on bulk-tissue proteomic measurements, which can obscure cell-type-specific protein–disease associations. ctPWAS models bulk protein abundance as a mixture of multiple cell types and estimates cell-type-specific genetic prediction weights without requiring single-cell proteomic reference data. These weights are integrated with GWAS summary statistics and a linkage disequilibrium (LD) reference panel to test protein–trait associations at both cell-type and tissue levels, accounting for cross-cell-type dependence.

Although designed for PWAS, ctPWAS can also be applied to transcriptomic data for methodological evaluation.

## Key Features

- **Cell-type-level PWAS:** Identify protein–trait associations across two or more cell types using bulk proteomics.
- **Cell-type composition:** Estimate sample-level proportions through marker-protein-guided deconvolution or supply externally estimated proportions.
- **Accurate, parsimonious genetic prediction:** Use mirror-statistic-based stability screening and weighted elastic-net regression.
- **Summary-statistics inference:** Perform cell-type-specific tests and tissue-level joint tests without individual-level GWAS genotypes.
- **Cross-cell-type adjustment:** Account for dependence among predicted protein abundances to reduce signal misattribution.

## Main Functions

| Step | Function | Purpose |
|---|---|---|
| Cell-type composition | `estimate_prior()` | Convert cell-type enrichment scores to initial proportions |
| | `pi_estimation_K()` | Refine proportions using bulk molecular measurements and marker features |
| | `deNet_composition_K_once()` | Run one K-component EM refinement |
| Genetic prediction | `ctPWAS_train_K()` | Train cell-type-specific elastic-net models with split-sample stability screening |
| Association testing | `ctPWAS_assoc_test_K()` | Perform cell-type-specific and tissue-level association tests using GWAS summary statistics |
| Utility | `run_gwas()` | Perform single-SNP GWAS for continuous or binary traits |

See `?function_name` in R for full argument and output documentation.

## Installation

ctPWAS requires R >= 4.1. Install dependencies:

```r
install.packages(c("remotes", "glmnet", "matrixStats"))

# Aggregated Cauchy Association Test
remotes::install_github("yaowuliu/ACAT")

# Cell-type enrichment analysis
remotes::install_github("AlmogAngel/xCell2")
```

Install ctPWAS:

```r
remotes::install_github("songxiaoyu/ctPWAS")
library(ctPWAS)
```

## Example Workflow

ctPWAS follows three steps: estimate cell-type proportions, train genetic prediction models, and perform association testing.

### Step 1. Estimate Cell-Type Proportions

Estimate sample-level cell-type proportions using marker-based enrichment scores and bulk molecular measurements. First construct cell-type enrichment scores, convert them to initial proportions using `estimate_prior()`, and refine them using `pi_estimation_K()`.

For proteomic applications, use marker proteins represented in the bulk proteomic dataset. Externally estimated cell-type proportions are also supported. The repository's supplied deconvolution example uses **transcriptomic** GTEx breast tissue expression data and epithelial, adipocyte, and fibroblast marker genes; it is an illustration of the workflow rather than a proteomic demonstration.

```r
library(xCell2)
data(markers)
data(expr)

cell_names <- unique(sub("#.*$", "", names(markers)))
custom_xcell2 <- methods::new(
  "xCell2Object",
  signatures = markers,
  genes_used = unique(unlist(markers, use.names = FALSE)),
  dependencies = list(),
  params = data.frame(celltype = cell_names, a = 1, b = 1, m = 1, n = 0),
  spill_mat = diag(1, length(cell_names), dimnames = list(cell_names, cell_names))
)

xCellScore <- xCell2::xCell2Analysis(
  mix = expr, xcell2object = custom_xcell2,
  minSharedGenes = 0.8, rawScores = TRUE, spillover = FALSE
)

cell_type_3 <- as.list(cell_names)
names(cell_type_3) <- cell_names
pi_prior <- estimate_prior(
  xCellScore = xCellScore, cell_types = cell_type_3,
  mu = c(0.4, 0.5, 0.1), lower = 0.01, upper = 0.98
)

marker_clean <- setNames(lapply(cell_names, function(ct) {
  unique(unlist(markers[grepl(paste0("^", ct, "#"), names(markers))]))
}), cell_names)

pi_hat <- pi_estimation_K(
  expr = expr, n_iteration = 20, prior = pi_prior,
  marker_list = marker_clean, seed = 1, verbose = FALSE
)
head(pi_hat)
```

### Step 2. Train Cell-Type-Specific Protein Prediction Models

Given bulk protein abundance, matched genotypes, and estimated cell-type proportions, train cell-type-specific genetic prediction models using `ctPWAS_train_K()`.

```r
data(x_example, y_example, pi_k)

fit <- ctPWAS_train_K(
  y = y_example,       # Bulk abundance for one molecular trait
  x = x_example,       # Samples x cis-SNPs
  pi_k = pi_k,         # Samples x cell types
  cov = NULL,
  yName = "Protein_A",
  alpha = 0.5,
  seed = 1,
  No_split = 11
)

fit$W                 # SNPs x cell types: prediction weights
fit$Num_SNP_model     # Number of selected SNPs
```

The procedure uses repeated split-sample fits to assess stability of genetic prediction weights and obtain empirical false discovery rate scores. These scores are incorporated as penalty factors in the final cross-validated elastic-net model to improve prediction accuracy and parsimony.

**Note:** The toy dataset is small, so `cv.glmnet` may warn about fewer than three observations per fold.

### Step 3. Perform Cell-Type-Level PWAS

Integrate cell-type-specific genetic prediction weights with GWAS summary statistics and an LD reference panel.

```r
data(gwas_example)
gwas_z <- gwas_example$Beta / gwas_example$se_Beta

res <- ctPWAS_assoc_test_K(
  W = fit$W,
  gwas_z_score = gwas_z,
  x_g = x_example,      # Toy LD reference; use ancestry-matched panel in practice
  n0 = 1000,
  n1 = 1000,
  family = "binomial",
  reg_scale = 0.01,
  regularization = "fixed"
)

res$p_join_vec         # Correlation-adjusted cell-type-specific p-values
res$p_join             # ACAT-combined tissue-level p-value
res$mode               # Joint test or fallback mode
```

For continuous GWAS traits, use `family = "gaussian"` (the `n0` and `n1` parameters are then unused). The `regularization = "estimate"` option estimates a regularization scale for the covariance matrix. When cell-type weights are all zero or predictions are nearly collinear, joint adjustment may be skipped; inspect `res$mode`.

In real applications, use an ancestry-matched LD reference panel (e.g., 1000 Genomes EUR when appropriate). SNPs must be allele-harmonized and identically ordered in `W`, `gwas_z_score`, and `x_g`.

### Optional: Run GWAS Using Individual-Level Data

```r
set.seed(1)
pheno <- rnorm(nrow(x_example))
gwas <- run_gwas(X = x_example, D = pheno, family0 = gaussian())
head(gwas)

# For case-control data with D coded 0/1:
# run_gwas(X, D, covar = covariates,
#          family0 = binomial(), method_binomial = "score")
```

The binomial score test is fast but returns only Z and P; use `method_binomial = "glm"` if effect estimates are needed.

## Reproducing Manuscript Analyses

The [`Analysis_code/`](Analysis_code) directory contains scripts for the simulation studies and real-data applications. External datasets (GTEx, TCGA, DRIVE, HERMES, and 1000 Genomes) are not distributed with the package. Edit the data paths at the top of the scripts before running them.

Run the heart PWAS workflow in order:

```bash

bash "$DIR/6.3_1000Genome_keep_eur_plink_hermes_pwas.sh"
Rscript "$DIR/6.4_HERMES_run_analysis_pwas.R"
Rscript "$DIR/6.5_plot_hermes_pwas.R"
```
